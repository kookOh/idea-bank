# 앱인토스 빌드 & 검증

사용자가 앱인토스 미니앱을 빌드하고 검증하려 합니다.

## 빌드 프로세스

```bash
# 1. 빌드 실행
npx granite build

# 2. .ait 파일 확인
ls -la dist/*.ait

# 3. 번들 사이즈 확인 (권장: 5MB 이하)
du -sh dist/*.ait
```

## 빌드 후 검증 체크리스트

### TDS 사용 검증
- [ ] 모든 UI 컴포넌트가 TDS 기반인지 확인
- [ ] 커스텀 CSS가 TDS 테마를 덮어쓰지 않는지 확인
- [ ] NavigationBar가 TDS 규격을 따르는지 확인
- [ ] 다크모드 지원 여부 확인

### 번들 최적화
- [ ] 불필요한 의존성 제거
- [ ] 이미지 최적화 (WebP 사용 권장)
- [ ] 코드 스플리팅 적용
- [ ] Tree shaking 확인

### 기능 테스트
- [ ] 핵심 기능 정상 동작
- [ ] 에러 핸들링 + 빈 상태 처리
- [ ] 오프라인 대응 (네트워크 끊김 시)
- [ ] 60fps 성능 유지

### 보안 검증
- [ ] window.open / location.href 미사용
- [ ] 외부 앱 설치 유도 없음
- [ ] XSS / injection 방지
- [ ] 민감 데이터 로컬 저장 없음

## 심사 제출 준비
1. 앱 스크린샷 5장 이상 준비
2. 개인정보 처리방침 URL 준비
3. 앱 설명 작성 (가이드라인 준수)
4. `.ait` 파일 업로드
