# IdeaHunter - Master Blueprint Part 1: 제품 비전 & 전략

> 최종 업데이트: 2026-03-10
> 버전: v0.4 (Foundation Pack)

---

## 1. 제품 비전

**"아이디어 발견부터 실행까지, AI가 매일 큐레이션하는 사이드 프로젝트 런치패드"**

IdeaHunter는 전 세계 7개 플랫폼(HackerNews, Reddit, ProductHunt, GitHub, PlayStore, AppStore, AppBrain)에서 트렌딩 비즈니스 아이디어를 자동 수집하고, AI(Groq LLM)로 한국어 시장성을 분석한 뒤, Claude Code/Codex가 즉시 실행할 수 있는 구현 프롬프트까지 자동 생성하는 올인원 아이디어 큐레이터이다.

### 핵심 가치 흐름

```
[발견] 7개 소스 자동 수집 (매일 6AM UTC 크론)
   |
   v
[분석] Groq llama-3.1-8b-instant로 한국어 AI 분석
   |   (요약, 시장규모, 난이도, 수익성, 경쟁도, 스택추천, MVP일수, 태그)
   v
[큐레이션] trend_score 알고리즘으로 우선순위 정렬
   |
   v
[실행] 원클릭 Claude Code 구현 프롬프트 자동 생성
   |   (마스터 프롬프트 / 5단계 프롬프트 / 앱인토스 전용 프롬프트)
   v
[구현] 프롬프트 복사 -> Claude Code 붙여넣기 -> MVP 코드 자동 생성
```

### 핵심 원칙

1. **무료 우선(Free-First)**: 모든 외부 서비스는 무료 플랜만 사용 (Vercel Hobby, Supabase Free, Groq Free)
2. **자동화 극대화**: 수집-분석-큐레이션-프롬프트 생성 전 과정 자동화
3. **한국어 중심**: 한국 인디 개발자를 위한 한국어 분석/요약/프롬프트
4. **실행 가능성**: 아이디어 탐색에서 끝나지 않고, 실제 코드 구현으로 연결

## 2. 핵심 사용자

### 2.1 주요 타겟: 한국 인디 개발자

| 속성 | 설명 |
|------|------|
| 프로필 | 1-5년차 프론트엔드/풀스택 개발자, 사이드 프로젝트 경험 1-2회 |
| 페인 포인트 | "뭘 만들지 모르겠다", "아이디어는 있는데 시작이 어렵다", "해외 트렌드를 한국어로 소화하기 힘들다" |
| 목표 | 수익을 낼 수 있는 사이드 프로젝트를 빠르게 론칭 |
| 도구 | VS Code, Cursor, Claude Code, Vercel, Supabase |
| 행동 패턴 | HackerNews/Reddit 매일 브라우징, ProductHunt 주 1회 체크 |

| 속성 | 설명 |
|------|------|

| 행동 패턴 | 프롬프트 기반 개발, 앱인토스 같은 낮은 진입장벽 플랫폼 선호 |

**페르소나 A: 김사이드 (28세, 프론트엔드 개발자)**

- "매일 HN/Reddit 훑는 데 30분씩 쓰는데, 한국 시장에 맞는 아이디어를 골라주면 좋겠다"
- IdeaHunter 사용 패턴: 매일 아침 대시보드 확인 -> trend_score 높은 아이디어 3개 분석 -> 프롬프트 생성 -> Claude Code로 주말에 MVP 구현

- IdeaHunter 사용 패턴: 앱인토스 적합도 점수(ait_score) 70 이상 필터 -> 분석 확인 -> 앱인토스 전용 프롬프트로 미니앱 구현

- 다양한 소스를 일일이 모니터링하기 힘들고, 수치적 근거가 필요
- IdeaHunter 사용 패턴: 주간 리뷰 때 다이제스트 페이지 참조 -> 소스/태그 필터로 관심 영역 분석 -> 팀 회의 자료로 활용

## 3. 핵심 기능 목록

### 3.1 아이디어 수집 (Collection)

| 기능 | 설명 | 구현 파일 |
|------|------|-----------|
| HackerNews 수집 | Top Stories API로 상위 아이디어 수집 | `lib/collectors/hackernews.ts` |
| Reddit 수집 | r/SideProject, r/startups 등 서브레딧 | `lib/collectors/reddit.ts` |
| ProductHunt 수집 | 일일 인기 프로덕트 (Bearer 토큰) | `lib/collectors/producthunt.ts` |
| GitHub 수집 | Trending repositories | `lib/collectors/github.ts` |
| PlayStore 수집 | 새로 뜨는 앱 (메가앱 필터 적용) | `lib/collectors/playstore.ts` |
| AppStore 수집 | 새로 뜨는 iOS 앱 (RSS) | `lib/collectors/appstore.ts` |
| AppBrain 수집 | Android 앱 트렌드 | `lib/collectors/appbrain.ts` |

**수집 파이프라인 특성:**
- 소스당 최대 10개 수집, 배치 중복 체크 (`source_url` IN 쿼리)
- `collectWithRetry` 래퍼로 최대 3회 재시도 (지수 백오프: 1초, 2초, 3초)
- `deduplicateByField` 유틸로 동일 필드 기준 중복 제거
- 메가앱 필터 (`mega-filter.ts`): Big Tech, 소셜, 스트리밍, 이커머스, 금융, 게임 등 80+ 패키지 프리픽스 자동 제외
- 하나의 수집기 실패 시 나머지는 정상 동작 (격리)
- 소스별 수집 결과는 `collect_logs` 테이블에 기록

### 3.2 AI 분석 (Analysis)

| 기능 | 출력 필드 | 모델 |
|------|-----------|------|
| 한국어 요약 | `summary_ko` (2-3문장) | llama-3.1-8b-instant |
| 시장 규모 추정 | `market_size` ("글로벌 $5B, 국내 500억") | llama-3.1-8b-instant |
| 난이도 평가 | `difficulty` (1-5) | llama-3.1-8b-instant |
| 수익성 평가 | `revenue_potential` (1-5) | llama-3.1-8b-instant |
| 경쟁 수준 | `competition` (1-5) | llama-3.1-8b-instant |
| 기술 스택 추천 | `recommended_stack` (["Next.js", "Supabase"]) | llama-3.1-8b-instant |
| MVP 기간 추정 | `mvp_days` (정수) | llama-3.1-8b-instant |
| 태그 분류 | `tags` (["SaaS", "AI", "B2B"]) | llama-3.1-8b-instant |
| 트렌드 점수 | `trend_score` (가중 산출) | 코드 (`calcTrendScore`) |

**트렌드 점수 산출 공식:**
```
base = score * 0.4 + comment_count * 0.3
potential = (revenue_potential / 5) * 40
ease = ((6 - difficulty) / 5) * 30
trend_score = round(base * 0.1 + potential + ease)
```

**안정성:** LLM 응답 실패 시 기본값 폴백 (description 앞 100자, 난이도 3, 수익성 3, ["Next.js", "Supabase"], 30일, ["기타"])

### 3.3 프롬프트 생성 (Prompt Generation)

| 기능 | 설명 | 생성 방식 |
|------|------|-----------|
| 마스터 프롬프트 | 전체 프로젝트 한 번에 구현하는 프롬프트 (DB/API/UI/기능/규칙 포함) | 템플릿 + LLM 기술 상세 |
| 단계별 프롬프트 | 5단계 분할: 초기화 -> DB/백엔드 -> 프론트엔드 -> 핵심기능 -> 테스트/배포 | 템플릿 기반 |
| 앱인토스 프롬프트 | 토스 미니앱 전용 (Granite/TDS/AdMob IAA 스택) | 코드 템플릿 (`formatAitPrompt`) |

**아키텍처 핵심 설계:**
- **템플릿 기반 생성**: LLM은 기술 상세(DB 스키마, API 엔드포인트, UI 화면, 핵심 기능)만 생성하고, 프롬프트 구조(한국어)는 코드 템플릿이 보장한다
- **LLM for tech details**: `llama-3.3-70b-versatile`로 아이디어 맞춤 기술 명세 생성 (temperature: 0.4)
- **폴백 기본값**: LLM 실패 시 `buildFallbackDetails`로 일반적인 웹앱 구조 제공
- **캐싱**: `generated_prompts` JSONB 컬럼에 `{ default, appintoss }` 구조로 저장
- **원자적 잠금**: `implementation_status` 필드로 동시 생성 요청 방지 (429 응답)
- **강제 재생성**: `force=true` 파라미터로 캐시 무시 가능
- **구현 규칙 강제**: "유료 서비스 절대 사용 금지" 등 프롬프트에 하드코딩

### 3.4 앱인토스 분석 (AIT Analysis)

| 기능 | 설명 |
|------|------|
| 적합도 점수 | 0-100점 앱인토스 적합성 평가 (`ait_score`). 광고수익잠재력 30% + 사용자참여도 30% + 구현용이성 20% + 심사통과가능성 20% |
| 카테고리 분류 | 유틸리티/라이프스타일/엔터테인먼트/교육/건강/소셜/게임/생산성 |
| 차단 사유 분석 | 금지 카테고리(금융, 투자, 디지털자산, 암호화폐, 주식 등) 사전 필터링 |
| 광고 수익 추정 | DAU/eCPM 기반 AdMob IAA 예상 수익 |
| 타겟 타입 결정 | `webview` vs `react-native` 권장 |

**동작 방식:**
- 온디맨드 분석 (사용자 "앱인토스 분석" 클릭 시 실행)
- `platform_analysis` JSONB 컬럼에 저장, 이후 캐시 반환
- 원자적 잠금 (`implementation_status = 'analyzing'`)으로 동시 분석 방지
- 앱인토스 전용 프롬프트: TDS 컴포넌트, Granite 빌드 도구, 심사 체크리스트 포함

## 4. 차별점

### 4.1 기존 방식 vs IdeaHunter

| 관점 | 기존 방식 | IdeaHunter |
|------|-----------|------------|
| 아이디어 발견 | 매일 5-7개 사이트 직접 탐색 (1-2시간) | AI가 7개 소스 자동 수집/큐레이션 (0분, 크론 자동) |
| 언어 장벽 | 영어 콘텐츠를 직접 읽고 해석 | 한국어 요약 + 시장 분석 자동 제공 (`summary_ko`) |
| 실행 가능성 판단 | 감으로 판단, 사후 후회 | 난이도/수익성/경쟁강도 1-5점 정량 분석 |
| 구현 시작 | 빈 에디터에서 시작, 구조 설계부터 | Claude Code 마스터 프롬프트 원클릭 생성 |
| 앱인토스 적합성 | 심사 기준 문서를 직접 읽고 판단 | AI가 적합도 0-100점 + 전용 프롬프트 자동 생성 |
| 비용 | ProductHunt Pro ($20/월), Exploding Topics ($39/월) 등 | 완전 무료 운영 ($0/월) |

### 4.2 6가지 차별화 요소

1. **7개 소스 통합 수집**: HN, Reddit, PH, GitHub, PlayStore, AppStore, AppBrain을 단일 대시보드에서 동시 모니터링
2. **AI 한국어 분석**: 영어 원문을 한국어로 요약 + 정량 시장 분석 + 기술 스택 추천
3. **실행 가능한 프롬프트**: 분석에서 끝나지 않고, Claude Code/Codex가 즉시 실행 가능한 구현 프롬프트(DB 스키마/API/UI/기능 포함) 자동 생성
4. **앱인토스 특화**: 한국 토스 미니앱 플랫폼 적합성 분석 + Granite/TDS 전용 프롬프트 생성 (경쟁 서비스에 없는 고유 기능)
5. **무료 스택 강제**: 프롬프트에 "유료 서비스 절대 사용 금지" 규칙 하드코딩, Vercel free + Supabase free만 사용
6. **AI 프로바이더 폴백 체인**: 로컬 CLI(Claude Code -> Codex) -> Groq API -> 하드코딩 기본값 순으로 최적의 프롬프트 품질 보장

### 5.1 경쟁 서비스 비교

| 서비스 | 가격 | 장점 | 단점 | IdeaHunter 우위 |
|--------|------|------|------|-----------------|
| **ProductHunt** | 무료 (Pro $20/월) | 최신 프로덕트 발견, 커뮤니티 투표 | 영어 전용, 분석 없음, 구현 지원 없음 | 7개 소스 통합 + 한국어 분석 + 프롬프트 생성 |

**IdeaHunter의 유일한 포지션:** 자동 수집 + 깊은 분석 + 실행 프롬프트 생성 (우측 상단 유일)

### 5.3 IdeaHunter 고유 경쟁력 (Moat)

1. **End-to-End 파이프라인**: 발견 -> 분석 -> 프롬프트 생성까지 원스톱 (경쟁 서비스는 발견만 제공)
2. **앱인토스 특화**: 토스 미니앱 적합도 분석은 세계 어디에도 없는 고유 기능
3. **AI 프로바이더 폴백 체인**: 로컬 CLI -> Groq 순 폴백으로 최적 품질 보장
4. **완전 무료 운영**: SaaS형 경쟁 서비스($20-79/월)와 달리 전체 운영 비용 $0
5. **한국어 최적화**: 글로벌 서비스에는 없는 한국어 분석/프롬프트 제공
